# C1 有效行统计

## 这一步在做什么

由脚本统计范围内的有效代码行（去掉空行和纯注释行），并按 P4 的职责和档位分到核心、重要、辅助三档。这些行数就是覆盖率的分母。

**这一步你不用填任何东西**，只需要运行脚本，然后处理脚本报出的问题。

## 开始前你需要

- P6 已完成

## 产出

`C1-lines.json`（脚本生成）

## 操作步骤

```bash
python3 工作流/scripts/bitsscore.py lines 评估记录/<评估ID>
```

脚本的规则：

- 去掉 `//` 和 `/* */` 注释；注释符号在字符串里面的不算注释。
- 去掉之后还有代码的行，才是有效行。
- 一行被多个职责覆盖时，取最高档。

## 输出的意思

| 输出 | 意思 | 要你做什么 |
| --- | --- | --- |
| `有效行 N：核心 a，重要 b，辅助 c；未归档 0` | 正常 | 进入 C2 |
| `未归档 X 行` | 有些有效行不属于任何职责 | 回 P4 补职责，或者在 P2 的 `excluded_globs` 中排除这些文件 |
| `警告：有 X 行看起来在操作资产或权限，却被定成了辅助档` | 可能定档过低 | 回 P4 复核问题 1（见 P4 卡的「完成检查」） |
| `注意：有职责区间没有落在统计范围内` | 某个职责的区间写错了文件，或者全是注释 | 回 P4 核对行号 |

## 完成检查

输出显示「未归档 0」，并且没有「警告」，或者警告已经按 P4 卡的要求处理过。
