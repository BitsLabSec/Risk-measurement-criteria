# P6 前期准备交付

## 这一步在做什么

用 P3–P5 的表格自动生成全量关系图，再按清单复核一遍，确认前期准备可以交给代码安全和链上评估使用。

## 开始前你需要

- `P5-roles-controls.json` 已通过检查
- `lines` 已经运行过，未归档 0 行

## 产出

- `P6-graph.md`：脚本生成的关系图，不要手改
- 前期准备的全部文件：`T0`、`P1`–`P5`、`gaps.json`

## 操作步骤

1. 生成关系图：
   ```bash
   python3 工作流/scripts/bitsscore.py graph 评估记录/<评估ID>
   ```
2. 打开 `P6-graph.md`，按下面的清单逐项复核。发现问题就回到对应步骤修改，然后重新生成。

## 复核清单

全部答「是」才算完成：

| # | 问题 | 不是的话回到 |
| --- | --- | --- |
| 1 | P1 的每个部署实例，`status` 都是 `confirmed` 吗？如果不是，`gaps.json` 里是否登记了缺口？ | P1 |
| 2 | P2 的每条源码记录，`verify_result` 都是 `match` 吗？如果不是，是否登记了缺口？ | P2 |
| 3 | 图中每个业务下面都有模块吗？ | P3 |
| 4 | 每个特权角色都连到了至少一个控制吗？ | P5 |
| 5 | 每个控制都连到了至少一个职责吗？ | P5 |
| 6 | 升级权限出现在图里了吗？ | P5 |
| 7 | `lines` 未归档 0 行，并且「疑似定档过低」的报警都处理过了吗？ | P4 |
| 8 | 每个 `blocks_denominator: true` 的缺口，你都确认过确实无法解决吗？ | 对应步骤 |

## 完成检查

```bash
python3 工作流/scripts/bitsscore.py validate 评估记录/<评估ID> --step P5
python3 工作流/scripts/bitsscore.py lines 评估记录/<评估ID>
python3 工作流/scripts/bitsscore.py graph 评估记录/<评估ID>
```

三条命令都没有报错，复核清单全部为「是」，这一步就完成了。
