# O2 读取清单

## 这一步在做什么

列出这次评估要读的**每一个链上对象和字段**，以及它们分别服务于哪个检查。下一步 O3 按这份清单去读，用什么工具读都可以。

清单之外的东西不要读。取证预算是 **30 + 15 × 业务数** 个对象，目的是防止无限制地翻查交易和无关地址。

## 开始前你需要

- `O1-scope.json` 已通过检查
- P5 的角色和控制（权限要追的对象）
- 每个业务的专项文件第 2–4 节（配置和资金要读的对象）

## 产出

`O2-targets.json`

## 操作步骤

按下面的顺序列，**先列必需的**：

1. **权限对象**（服务于 `H1@BZ01` 这类检查）。对 P5 里每个后果为 H1–H3 的控制，列出：
   - 权限凭证本身（Sui 的 Cap 对象、EVM 的 owner 或 role）；
   - 当前持有人；持有人是多签的，多签本身和它的门限、成员；成员还是多签的，继续往下列；
   - 时间锁合约及其最短等待时间；
   - 升级凭证（Sui 的 UpgradeCap，EVM 的代理管理员）。
2. **共享配置**（服务于专项第 3 节）。全局配置、价格源配置、利率模型等。共享的只列一次。
3. **市场对象**（服务于专项第 3、4 节）。O1 里登记的每个市场。
4. **资金对象**（服务于专项第 4 节）。金库、储备、奖励金库的余额。
5. **预言机**（只对借贷、杠杆、永续、CDP，服务于 OR-1 到 OR-4）。价格对象、最大价格年龄参数。写死在代码里的常量不用列，O6 里直接引用代码位置。
6. 最后才列 `optional` 和 `disclosure` 的对象。

每个对象的 `fields` 写清要读哪个字段、它是什么意思、单位是什么。

## 怎么判断

| 问题 | 规则 |
| --- | --- |
| 这个对象要不要列？ | 能说出它服务于哪个检查编号的，才列。说不出来的不列 |
| `priority` 填什么？ | 专项表中硬约束或警戒要用的 → `required`；只出现在「只披露」里的 → `disclosure`；其他 → `optional` |
| 需要扫历史交易或枚举所有用户才能得到的数？ | 不列。这类数不计分（[骨架 3.3](../../评分骨架.md)），O5／O6 里对应检查填 `q_aggregate_not_stored: yes` |
| 同一个地址服务于多个检查？ | 只写一条，`serves` 里列全部检查 |

## 填写示例

```json
{
  "targets": [
    {"id": "OT01", "chain_id": "sui:mainnet", "address": "0x1a…", "kind": "capability",
     "fields": [{"name": "owner", "meaning": "StorageAdminCap 当前持有人地址"}],
     "serves": ["H1@BZ01", "H2@BZ01"], "priority": "required", "reason": "P5 控制 K01、K02 的凭证"},
    {"id": "OT02", "chain_id": "sui:mainnet", "address": "0xab…", "kind": "market_or_pool",
     "fields": [{"name": "ltv", "meaning": "最大借款比例，单位 1e27"},
                {"name": "liquidation_threshold", "meaning": "清算线，单位 1e27"},
                {"name": "liquidation_bonus", "meaning": "清算奖励，单位 1e27"}],
     "serves": ["L-C2.1@MK01"], "priority": "required", "reason": "Lending 专项 L-C2.1"}
  ]
}
```

## 完成检查

```bash
python3 工作流/scripts/bitsscore.py validate 评估记录/<项目>/<评估ID> --step O2
```

检查会打印「已列 N 个目标，预算 M」。超出预算时会报错。

## 常见错误

- 去翻历史交易找「谁调过这个函数」。权限只看**当前**持有人。
- 为了披露项读一大堆池子。先保证必需检查。

## 卡住了怎么办

只列必需对象也超出预算：在 `gaps.json` 登记（`step` 填 `O2`，`blocks_denominator` 填 `true`），交人处理。
