# BitsScore 评级标准

当前优先服务 Web3 原生、尤其是已服务的 DeFi 项目。按评估问题分别展示结果，不将采购安全服务或宣传指标直接等同于安全能力。

| 模块 | 核心问题 | 标准 |
| --- | --- | --- |
| 代码安全 | 哪些代码已由适用审计或形式化验证覆盖，报告记录了哪些风险 | [代码安全评分标准](./code-security-rating-standard.md) |
| 链上安全 | 权限管理、参数配置、资金与外部依赖如何影响协议长期正常运行 | [通用链上安全评估标准](./合约类型评估标准/通用链上安全评估标准.md) · [业务类型专项](./合约类型评估标准/README.md) |
| 业务攻防 | 评级侧从最终渗透报告识别实际业务覆盖与保留风险，独立完成映射、权重及评分 | [Web3 业务攻防评级标准](./web3-business-security-rating-standard.md) |
| 安全运营与披露补充说明 | 整理前三部分未覆盖的联系、反馈、运营责任及补充保障信息，不设置独立评分 | [安全运营与披露补充说明](./security-operations-disclosure-supplement.md) |
| 盘外情报 | 公开身份、披露、市场上下文、治理与攻击面枚举的完备度；小项四态计分映射到 100 | [盘外情报评级标准](./offchain-intelligence-rating-standard.md) |

新项目先核验生产部署并按功能划分业务。代码安全和链上评估共用生产基线和业务范围。链上先算各业务的分项并执行适用的业务封顶，再对每个大项内的适用业务等权平均，按 30%／30%／40% 汇总，最后执行适用的项目级封顶。历史结果按原版本追溯。 [前期准备](./assessment-preparation.md) · [链上评估复用指南](./合约类型评估标准/链上评估复用指南.md)

## 使用边界

- 前三部分按各自规则展示，不强行统一分数含义，目前不合成统一项目总分；第四部分为补充说明，无独立分数或评分门槛。盘外情报按[盘外情报评级标准](./offchain-intelligence-rating-standard.md)单独计分（符合 2／部分符合 1／不符合 0／不适用不计分母，映射到 100），不并入前三部分，也不替代第四部分的无分披露整理。
- 审计和渗透报告不按厂商分档，同类报告同等采信；对已覆盖且通过部分暂认定大致合格，不在评级中重新评价交付质量。
- 使用终审报告及已有交付结论，不新增草稿／中间版本的问题合并流程。报告中的中心化问题保留说明，不参与代码或业务攻防风险扣分，只根据当前链上权限与控制信息评价。
- 链上以独立 snapshot 判断；代码和业务攻防使用仍适用的最终报告及验证证据；第四部分整合既有资料和项目说明，标注来源与已有核验范围，不默认追加测试或演练。
- 同一证据可以复用，事实、技术原因、实际后果和运行安排分别解释，不重复累计风险金额或评分处罚。
- 未覆盖、证据不足、明确失败和不适用分别标注。链上适用的必要检查缺证时以 0 分结项。已核验的生产代码缺少适用审计证据时，代码照计分母，覆盖贡献为 0。
- 未取得的材料按影响范围披露，各维度按其结项规则交付。正式生产源码或职责分母无法核实时，代码安全交付「无法评分」及已核实明细。
- 子项拆分沿用父项总权重，按业务影响保持合理粒度；不要求所有项目采用精确到代码行或接口数的统一拆分。
- 保险、认证、团队、赏金和运营资源可补充披露，不因其存在直接给技术安全加分。
- 链上专项覆盖借贷、现货兑换、杠杆仓位、金库、条件订单及奖励和兑付类业务，既有永续及同质化代币专项也按共用流程接入。每项目每轮合计最多核验 50 个链上目标。评估结论按其实际控制、配置、资金义务和必要依赖限定范围。 [业务类型专项索引](./合约类型评估标准/README.md)

文档内版本为规则引用依据。

## 配套交付说明

- [合约审计与渗透测试报告交付需求](./security-assessment-report-delivery-requirements.md)：区分报告正文、覆盖附件及评级侧维护信息，供实际交付使用。
- [Web3 业务渗透测试服务与交付规范草案](./web3-penetration-testing-service-spec.md)：明确业务范围、测试条件、服务项、内部测试准备、覆盖记录及报告交付，供团队讨论和试用。
- [Web3 业务渗透测试客户服务范围信息收集表](./web3-penetration-testing-client-intake.md)：客户选择十项服务，并逐项确认测试对象、条件、允许操作及授权边界，供测试执行和报告披露使用。

## 展示时间口径

| 时间 | 表示什么 |
| --- | --- |
| 报告／测试日期 | 安全服务原交付及测试对应的时间 |
| 最新适用性确认时间 | 最近一次确认既有证据仍对应当前版本、配置或范围的时间，不代表重新测试 |
| 链上区块时间 | 当前 snapshot 所代表的状态时点 |
| 补充资料／页面更新时间 | 信息整理或呈现的时间，不替代前述证据时间 |

已有材料没有某项时间时标未提供，不为填齐字段补做安全评估。
