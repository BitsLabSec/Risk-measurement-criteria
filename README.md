# BitsScore 评级标准

当前优先服务 Web3 原生、尤其是已服务的 DeFi 项目。按评估问题分别展示结果，不将采购安全服务或宣传指标直接等同于安全能力。

| 模块 | 核心问题 | 标准 |
| --- | --- | --- |
| 代码安全 | 哪些代码逻辑已被审计和验证，最终报告仍保留什么风险 | [代码安全评分标准](./code-security-rating-standard.md) |
| 链上安全 | 按协议类型评价当前控制、配置、依赖及适用的资金状态 | [Lending 链上安全评估标准](./合约类型评估标准/lending-onchain-security-rating-standard.md)、[DEX 链上安全评估标准](./合约类型评估标准/dex-onchain-security-rating-standard.md)、[收益金库链上安全评估标准](./合约类型评估标准/yield-vault-onchain-security-rating-standard.md)、[永续合约链上安全评估标准](./合约类型评估标准/perpetuals-onchain-security-rating-standard.md)、[同质化代币链上安全评估标准](./合约类型评估标准/fungible-token-onchain-security-rating-standard.md) |
| 业务攻防 | 哪些实际业务及支撑系统已通过适用的渗透与业务验证 | [Web3 业务攻防评级标准](./web3-business-security-rating-standard.md) |
| 安全运营与披露补充说明 | 整理前三部分未覆盖的联系、反馈、运营责任及补充保障信息，不设置独立评分 | [安全运营与披露补充说明](./security-operations-disclosure-supplement.md) |
| 盘外情报 | 公开身份、披露、市场上下文、治理与攻击面枚举的完备度；小项四态计分映射到 100 | [盘外情报评级标准](./offchain-intelligence-rating-standard.md) |

链上通用检查项、五类专项映射和评分规则见[通用链上安全评估标准](./合约类型评估标准/通用链上安全评估标准.md)。

## 使用边界

- 前三部分按各自规则展示，不强行统一分数含义，目前不合成统一项目总分；第四部分为补充说明，无独立分数或评分门槛。盘外情报按[盘外情报评级标准](./offchain-intelligence-rating-standard.md)单独计分（符合 2／部分符合 1／不符合 0／不适用不计分母，映射到 100），不并入前三部分，也不替代第四部分的无分披露整理。
- 审计和渗透报告不按厂商分档，同类报告同等采信；对已覆盖且通过部分暂认定大致合格，不在评级中重新评价交付质量。
- 使用终审报告及已有交付结论，不新增草稿／中间版本的问题合并流程。报告中的中心化问题保留说明，不参与代码或业务攻防风险扣分，只根据当前链上权限与控制信息评价。
- 链上以独立 snapshot 判断；代码和业务攻防使用仍适用的最终报告及验证证据；第四部分整合既有资料和项目说明，标注来源与已有核验范围，不默认追加测试或演练。
- 同一证据可以复用，事实、技术原因、实际后果和运行安排分别解释，不重复累计风险金额或评分处罚。
- 未覆盖、证据不足、明确失败和不适用分别标注；未知不能剔除后变成满分。
- 未知和关键遗漏按实际受影响范围展示，不清空无关结论；已有资料不足以支持全项目结论时先展示分项及缺口，不为补齐信息默认增加测试或穷尽采集。
- 子项拆分沿用父项总权重，按业务影响保持合理粒度；不要求所有项目采用精确到代码行或接口数的统一拆分。
- 保险、认证、团队、赏金和运营资源可补充披露，不因其存在直接给技术安全加分。
- 链上当前覆盖 Lending、DEX、收益金库、永续合约与同质化代币，各自采用适用范围和检查项；其他协议类型后续补充，不把 Lending 的专属参数套给其他 DeFi 类型。DEX 不预设 Uniswap 架构，不默认全量扫描交易对。收益金库不限定链或架构，资金分布、退出状态及受影响敞口只展示，不独立评分。
- 永续合约按公共控制、共享入口和必要依赖的实际作用范围分别计分，结算异常按链上已有记录披露。
- 同质化代币分别评价发行与资产控制权限、当前转账与收费配置。前十大持仓和市值仅作后续展示补充。

文档内版本为规则引用依据。

## 展示时间口径

| 时间 | 表示什么 |
| --- | --- |
| 报告／测试日期 | 安全服务原交付及测试对应的时间 |
| 最新适用性确认时间 | 最近一次确认既有证据仍对应当前版本、配置或范围的时间，不代表重新测试 |
| 链上区块时间 | 当前 snapshot 所代表的状态时点 |
| 补充资料／页面更新时间 | 信息整理或呈现的时间，不替代前述证据时间 |

已有材料没有某项时间时标未提供，不为填齐字段补做安全评估。
