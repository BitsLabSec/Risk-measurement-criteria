# 链上专项模板

所有类型专项都按这个模板写。专项**只能**写以下内容：

- 这类业务的必要操作；
- 三个大项各自要读哪些对象和字段；
- 用什么公式计算；
- 硬约束（违反记 0）和警戒阈值（触发记 60）。

专项**不能**写以下内容：

- 新的档位或档内扣分；
- 新的汇总方式、权重或封顶；
- 证据不足时的另一套处理方式；
- 历史版本的规则（历史版本放 `archive/`）。
- 需要扫描历史交易或事件、枚举全部用户或仓位才能得到的数值的阈值。这类数值只能披露（[评分骨架第 3.3 节](../评分骨架.md)）；
- 预言机时效、置信区间、排序器检查的阈值。统一引用[通用预言机检查 OR-1～OR-4](./链上安全评估标准.md#53-通用预言机检查or)；
- 「主流资产」的另一套口径。统一引用[通用标准第 4.3 节](./链上安全评估标准.md#43-主流资产的口径)。

上述内容一律以[链上安全评估标准](./链上安全评估标准.md)为准。

**检查表会被脚本直接读取。** 工作流脚本按下面的表格行格式，从专项文件里读出每个专项必须检查的编号，并判断哪些行「只披露」。因此：

- 第 3、4 节的检查表保持 7 列，列的顺序不要改；
- 每行第 1 列是编号（如 `L-C2.1`），第 2 列是归属（`C1`–`C3`、`F1`、`F2`、`D1`、`D2`）；
- 只披露、不计分的行：「硬约束」列写 `—`，「警戒阈值」列写「只披露」；
- 第一行写 `- 版本 vX.Y`，交付 JSON 从这里读专项版本；
- 某一行的定档要由脚本按公式计算时，先在脚本的公式表里登记，见[交付物字段表 · 由脚本计算的公式](../工作流/交付物字段表.md#六由脚本计算的公式)。
