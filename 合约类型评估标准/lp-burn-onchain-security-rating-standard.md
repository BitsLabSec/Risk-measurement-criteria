# LP 永久封存、收益领取及历史补偿链上安全评估专项

版本 v0.3｜2026-11-24。覆盖永久封存 LP 后保留的手续费及奖励领取，以及具有固定额度或期限的存量补偿。按产品实际承诺划分范围。 [通用链上标准](./通用链上安全评估标准.md)

**权限管理。** 沿能转移底层封存头寸、改写收取人或补偿凭证、阻断领费／领奖／补偿的角色和升级路径找实际控制主体。核对已生效的角色、门限、时间锁时长和可绕过路径，按代码及当前权限配置查危险操作控制者能否禁用已设计的领取入口。已部署的领取解限备份失效、独立主路径的权限配置仍有效时，核对通用权限的备份退化扣分。 [通用权限分表与扣分](./链上评估复用指南.md#13-第三步评估权限管理)

## 1. LP 永久封存及保留领取权

1. **先定对象和权利。** 固定部署和快照，确认凭证对应的原 LP 头寸、底层池、所保留的手续费和奖励权利，以及用户接受的本金封存条款。永久封存后无本金返还权时，给本金赎回检查标 N/A。登记池数只表示范围线索。
2. **参数配置。** 核对池、资格区间、费或奖励币种、凭证条件及版本，确认领取所用的底层头寸与原承诺匹配。核验当前领费和领奖入口、冻结和替代路径。已证实错绑、改写保留权益或阻断到期领取时，按实际受影响范围判档。
3. **资金与外部依赖。** 按币确认底层池中归属的手续费或奖励、可动用的付款对象，以及实际可验证的应付或受支持上界。底层 LP 头寸只登记一次。共享奖励库按可证明的分配和可动用规则解释，记录涵盖的池和其他付款责任。现有池的领取、付款与凭证版本依赖逐项核实。市场价格变化作为头寸经济表现披露。

## 2. 固定期限补偿计划

1. **定位有效义务。** 记录政策所覆盖的资产和用户范围、补偿币种、资格／凭证匹配、发行时承诺、阶段到期与已领取。用部署的精度和期次规则核对分期总额、已对外承诺的金额、一次性或分期领取约束、当前暂停和版本状态。到期前的正常等待按条款判断。
2. **核算可付余额。** 有可信计划级总承诺及累计已付时，按同币计算 `剩余义务 = 生效承诺总额 − 累计已付`。按当前分期、结算规则和承诺的资金预留要求确定本轮需要覆盖的金额，再与可按期支取的专用同币余额比较。逐期应付与全部剩余承诺分别记录。共同使用同一补偿计划的产品引用同一余额和义务。计划级付款覆盖与某张凭证当前合格属于两项证据。余额已覆盖固定同币义务时，安全垫阈值须有适用依据。
3. **核验取回路径。** 检查按期领取是否直接从同币余额支付，是否还依赖新的报价、签名、再次结算或充值。如有依赖，按当前链上证据和实际期限核验及判断现存替代路径。

## 3. 分档及交付

对应范围的配置保护、现存应付与必要路径核验通过归 100 档。达到预设警戒或异常部分受限且同范围有可验证的剩余路径归 60 档。硬约束违反或必要领取完全受阻且无替代归 0 档。先按结项规则确定适用状态，同一业务范围及大项取最低适用上限，再累计尚未用于定档的独立问题。单一事实取适用最高扣量。纯备用失效且独立主路径仍按原条件完整覆盖、无新增负担时适用 1 分条款。符合 3 分条件须证明独立次要业务功能失效。 [档内计算](./通用链上安全评估标准.md#13-先定档再计算档内分)

按正式范围及本轮目标额度完成核验。未取得证据的保护或替代按未具备相应保护计分。结项时仍缺可用证据的适用必要检查记 0，其所属计分模块仍纳入大项分母。分别记录「证据未取得」和「已证实失败」。未经证实的选配项仅披露。已证实不适用的项记 N/A。同一根因在同一范围造成同一后果时，由责任项计分。仅引用的结果标出责任项，引用本身不进入分母。 [证据缺失与结项](./通用链上安全评估标准.md#5-证据缺失去重与结项)

先确定各大项得分，再按复用指南计算业务和项目原始分，并在相应范围分别应用风险封顶。局部风险对应受影响的业务，项目封顶须核对全项目的控制或后果。缺证导致的检查 0 分按结项规则计入原始分。0 分封顶须有确证。 [项目和业务风险封顶](./链上评估复用指南.md#项目和业务风险封顶)
