# BitsScore 杠杆仓位链上评估标准

版本 v0.3，2026-11-24。适用于通过抵押、借款和交易建立杠杆仓位，且须经减仓、还款、清算或提款取回权益的业务。业务可以使用外部借贷市场。先从产品范围确定实际方向和借款来源。各表的 100／60／0 是档位上限。 [通用判据](./通用链上安全评估标准.md) · [范围、权限和证据流程](./链上评估复用指南.md)

## 1. 最小采集范围

以一个已声明市场或有明确共同配置的市场组为单位，固定生产入口、仓位管理组件、实际使用的借贷储备、计价来源及结算组件。选定资产和方向后，记录哪些操作依赖哪个组件、账户须满足哪些资格和限制。优先读取共享配置、储备和必要入口，按项目每轮 50 个目标的总额度停止采集。仓位总资产和债务可用已核验的汇总。缺少这些数据时只影响需要它的检查，结项按第 4 节记分。

**权限管理。** 沿能处分抵押或改写仓位权益、变更存量仓位条件、阻断减仓／还款／提款的路径查实际控制主体。核对已生效的角色、门限、时间锁时长和可绕过路径，并查危险操作控制者能否禁用已设计的减仓、还款或提款入口。外部储备的控制者若可达到同一后果，按可达范围计入。备用解限角色证实失效且按权限配置主恢复路径仍有效时，采用通用权限的备份退化扣分。若实际授权门限降低或生效权限已允许关闭必要退出入口，按通用规则重新定档。 [通用权限分表与扣分](./链上评估复用指南.md#13-第三步评估权限管理)

## 2. 参数配置

| 通用类 | 读取及计算 | 判定 |
| --- | --- | --- |
| C1 绑定 | 核对基础资产、抵押品、借款、储备、仓位、价格对象和交易组件的实际绑定。统一精度、报价方向和计价单位。使用实际方向及模式值。 | 绑定正确并进入实际消费路径归 100 档。已核实错绑造成错误记账、估值或结算归 0 档。 |
| C2 开仓与清算 | 按借贷部分的有效初始借款比例、清算线、总扣押、清算量和利率规则计算。外部储备的限额、敞口及借款资格按真实入口逐层核对。 | 适用的必要约束和联动通过归 100 档。确认允许新增仓位一开始即违反应有的清算边界、或保护关系违反硬约束归 0 档。有额外经济警戒的，须有适用专项依据。 |
| C2 允许的报价不确定性 | 读取消费端真正允许的最大价格不确定性、时效、折扣或保守估值，比较该约束与已验证的开仓安全余量。 | 只有已采用且适用的警戒才归 60 档。当前输入有效性归资金与外部依赖。 |
| C3 必要操作 | 区分新增杠杆和存量减仓、还款、清算、合资格提款。读确认生效的暂停及限制，核实还清债务后的提款路径。 | 按适用条件可用归 100 档，异常部分受限且仍有同范围路径归 60 档，完全受阻且无有效替代归 0 档。 |

若代码机制满足 Lending 专项的适用条件，按该专项计算 `b`、`λ`、清算总扣押与利率。`1 − b / λ` 表示在其模型假设下从最大发放到开始清算的距离。必要操作、名义费率与风险结论按各自作用记录。 [Lending 专项](./lending-onchain-security-rating-standard.md)

在 **Cetus ETH/USDC 已确认的历史试评**中，用有效 `b`、`λ`、已允许的抵押相对不确定性 `εc`、债务相对上移 `εd` 计算 `H情景 = (λ / b) × (1 − εc) / (1 + εd)`。该式用于接近开仓上限、报价方向归一、模型成立且额外置信折扣未启用的情景。在此口径下，配置允许的不确定性足以令 `H情景 < 1` 时命中 60 警戒。这个结果描述**允许的配置边界**，当前观察报价和头寸损失另有证据要求。是否适用于其他市场须先验证价格消费公式、保守估值和临界条件。同源的两个交易方向使用同一警戒记录。 [Cetus 已采用的保护缺口规则及 Margin 检查](../research/cetus-configuration-assessment-346896130.json)

## 3. 资金与外部依赖

| 通用类 | 读取及计算 | 判定 |
| --- | --- | --- |
| F1 真实义务 | 分清项目直接保管的资产、用户仓位归属及外部储备。读取按各币种和期限可执行的还款、结算及提款金额，记录保护条件。外部储备余额属于外部流动性。 | 对明确已到期的固定义务，确认为足额且可支付归 100 档，实际无替代的硬缺口归 0 档。缺仓位汇总时保留局部事实。汇总为该范围资金义务的必要证据时，结项给该检查记 0 并标明原因。 |
| F2 资金可达 | 在实际连接的每笔外部储备记录可用同币现金、流出限额余量、权限和等待条件。诊断某操作的即时现金边界时，同时受该储备实际现金及适用限额约束。当前付款需求按合约到期义务和已核实的合资格提款请求确定。预先采用的情景需求单独列明分母。 | 足以支持所声明操作归 100 档。预设警戒命中或异常部分出金受限且同范围仍有结果归 60 档。必要支付完全受阻且无有效替代归 0 档。 |
| D1 有效输入 | 核对最终消费的价格对象、时间、置信条件及有效性检查。使用价格的路径和普通还款等无需价格的路径逐条登记。 | 必要输入有效或已证实由备用完整承接归 100 档。按实际影响判部分受限或全阻断。 |
| D2 依赖和退出 | 分别检查新增借款、存量减仓或清算、正常还款、还清后提款。替代路径必须能在同一范围和要求的期限内生效。 | 分别记录当前操作和预先采用的停供情景。按同一范围和操作核实还款与退出能否继续。已披露的备用配置需核验实际可用性。 |

实际资金可用边界按原币计算。确认共享外部储备可用现金后，可以报告它能支持的出金量或已采用的情景，不能据此将储备全量算成项目自有偿付资本。只有适用规则预先采用了单一报价来源停止的情景才用于计分。使用真实时效触发点，保持其他条件不变，检查哪些必要路径继续。情景和当前异常分别记录。Cetus 历史案例中，报价过期限制了依赖报价的新增和风险处置，普通还款及还清后合资格提款仍有独立路径，按该次情景记录部分受限。 [Cetus 资金底稿](../research/cetus-funds-dependencies-review-346896130.json) · [当轮停供情景及版本](../research/cetus-funds-dependencies-method-research-2026-11-20.json)

## 4. 汇总与交付

配置、资金与外部依赖分别计分。在对应市场与权益范围内，先按结项规则确定适用状态，取独立检查项最低档位上限，再累计未定档的独立有据问题。同一事实取适用最高扣量。纯备用削弱或失效，独立主路径仍按原条件完整覆盖且无新增负担时扣 1 分。独立次要业务功能失效才适用扣 3 分。0 档固定为 0。 [档内计算](./通用链上安全评估标准.md#13-先定档再计算档内分)

按正式范围及本轮目标额度完成核验。未取得证据的保护或替代按未具备相应保护计分。结项时仍缺可用证据的适用必要检查记 0，其所属计分模块仍纳入大项分母。分别记录「证据未取得」和「已证实失败」。未经证实的选配项仅披露。已证实不适用的项记 N/A。同一根因在同一范围造成同一后果时，由责任项计分。仅引用的结果标出责任项，引用本身不进入分母。 [证据缺失与结项](./通用链上安全评估标准.md#5-证据缺失去重与结项)

先确定各大项得分，再按复用指南计算业务和项目原始分，并在相应范围分别应用风险封顶。局部风险对应受影响的业务，项目封顶须核对全项目的控制或后果。缺证导致的检查 0 分按结项规则计入原始分。0 分封顶须有确证。 [项目和业务风险封顶](./链上评估复用指南.md#项目和业务风险封顶)

| 大项与检查 | 档内扣分触发及证据 | 换档边界 |
| --- | --- | --- |
| 配置 C1 对象与单位 | 机制已有的储备或币种绑定交叉校验失效，以当前绑定和消费代码证实；主绑定、精度及全部相关操作仍正确，扣 1。 | 已证实必要绑定或精度错误导致仓位、价格或结算误算，记 0。 |
| 配置 C2 开仓与清算 | 已部署的附加敞口保护范围缩小，经实际抵押／借款方向和有效参数复算，开仓、清算及必要约束均达标且未命中警戒，扣 1。 | 命中专项已采用的风险警戒记 60；开仓即违反清算硬边界或必要约束失效记 0。 |
| 配置 C2 报价不确定性 | 可核实消费端可选的第二道不确定性防护退化，正常价格路径、有效折扣和已采用的开仓警戒仍满足，扣 1。 | 用实际采用的安全余量公式证实命中警戒记 60；违反确定的价格保护硬约束记 0。 |
| 配置 C3 存量操作 | 配置导致原有一键减仓后提款不能组合执行，已证实分开执行仍对同一范围全部有效且按时完成，扣 2。 | 部分存量必要操作异常受限而同范围仍有可用路径记 60；必要操作完全受阻且无替代记 0。 |
| 配置 C3 次要仓位功能 | 原已提供的批量仓位调整入口因生效配置停用。逐仓操作仍可执行全部必要调整，减仓、还款、清算及提款条件保持有效，扣 3。 | 一旦逐仓路径无法覆盖原必要权益，按实际受限程度和硬约束重新定档。 |
| 资金 F1 仓位义务 | 已指定为对应应付提供保护的备用同币余额可用额收缩，当前已证明同币义务仍按期足额履行且未命中警戒，扣 1。 | 命中已采用的资金警戒记 60；违反到期同币支付硬约束且无有效资金来源记 0。 |
| 资金 F2 外部储备与可达资金 | 以储备状态、出金额度和交易路径证实需额外一次还款释放或调拨步骤，同市场和方向仍可按期足额履行，扣 2。 | 有异常部分可达且同范围仍有可执行路径记 60；必要资金完全不可达且无替代记 0。 |
| 依赖 D1 报价值与置信度 | 独立备用价源已证实缩小覆盖，当前消费端有效主价格仍覆盖各必要路径，且无额外操作负担，扣 1。 | 当前必要报价失效，部分必要操作受限且同范围仍可继续的记 60；同项必要操作全阻断且无有效报价替代记 0。 |
| 依赖 D2 执行与退出 | 次要路由的组合减仓功能已不可用，原因在外部执行组件。合资格用户仍可用另一条经核实的生产路径完整减仓、还款及提款，扣 3。 | 按实际操作判断部分受限 60 或无替代的完全阻断 0。普通还款可用仅证明对应还款路径，不能据此认定必要退出完整。 |

以实际市场、币种和方向为行，记录快照、原值单位、应用公式及假设、当前或情景状态、定档依据、档内扣分及最终分。区分错绑导致的输入问题与输入来源自身失效。同一原因、同一范围、同一后果只计一次，申报范围外的市场单列。历史试评沿用其当轮分值、条件和范围。
