# 五类链上标准的适用边界

本页保留各专项差异。共同检查项、评分矩阵、证据及去重规则统一见[通用链上安全评估标准](./通用链上安全评估标准.md)。

| 规则或指标 | 专项适用边界 |
| --- | --- |
| 必要依赖 | Lending、DEX、收益金库及永续单列依赖分；Token 将必要外部转账校验纳入配置。引用其他模块的检查不重复计分。 |
| 价格偏离及来源封顶 | Lending 的报价偏离阈值与来源可信性 40／0 封顶，仅应用于其专项规定的条件。 |
| 资金与头寸 | Lending 保留流动性、头寸及缺口的单快照评估，数值评分阈值待定。收益金库展示资金分布及敞口。永续披露可直接核验的结算异常。 |
| DEX 池与 Token 市场数据 | DEX 不默认全量扫描交易池；Token 前十大持仓与市值预留展示，不计安全分。 |
| 中心化问题 | 报告中的中心化问题保留说明，其风险等级不参与代码及业务攻防风险封顶；链上权限依据当前控制路径评价。 |

五类专项的范围和原文见[分类索引](./README.md)。当前未确定跨市场、跨模块或跨类型的项目总分公式。
