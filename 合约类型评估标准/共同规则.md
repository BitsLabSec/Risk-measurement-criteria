# 五类链上标准的适用边界

本页保留各专项差异。共同检查项、评分矩阵、证据及去重规则统一见[通用链上安全评估标准](./通用链上安全评估标准.md)。

| 规则或指标 | 专项适用边界 |
| --- | --- |
| 必要依赖 | Lending v0.12 单列预言机来源与配置韧性分；DEX、收益金库及永续按各自专项检查必要依赖；Token 将必要外部转账校验纳入配置。引用其他模块不重复计分。 |
| 价格偏离及来源封顶 | Lending v0.12 不再以独立参考价或来源可信性调查为必评分前提；现成价格比较为选配披露，旧版偏离阈值及 40／0 来源封顶退出本版基础公式。 |
| 资金与头寸 | Lending v0.12 必采披露市场资金总量、直接位置及比例，借款人抵押总额、HF 分布、Top N、待清算和坏账总额暂不开展。收益金库及永续仍按原专项处理。 |
| DEX 池与 Token 市场数据 | DEX 不默认全量扫描交易池；Token 前十大持仓与市值预留展示，不计安全分。 |
| 中心化问题 | 报告中的中心化问题保留说明，其风险等级不参与代码及业务攻防风险封顶；链上权限依据当前控制路径评价。 |

五类专项的范围和原文见[分类索引](./README.md)。Lending v0.12 已明确本次声明范围内的资产权重及权限／配置／预言机最低总分；其他类型及跨类型项目总分仍未定义。Lending 的多签判档以完整路径最少不同密钥数为准，有效 k≥2 多签计入 B／D。

上述是正式口径。[链上评估复用指南](./链上评估复用指南.md)另行记录了 Lending 三模块加权试评与跨类型采集方法；未将 NAVI 权重和阈值迁移给其他类型。

Lending v0.12 权限采用统一授权／延迟表：单签无保护 0，单签有效 24／48 小时 40／50，多签 80／85／95；跨关键域关联模块一次扣1，60及格。辅助权限仅披露；已有关键授予、组合及恢复旁路必须进入路径，重叠密钥按 AND／OR 去重。其他模块沿用 v0.10。
